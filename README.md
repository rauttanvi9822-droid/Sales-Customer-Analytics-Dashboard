# 📊 Sales & Customer Analytics Dashboard

## 📌 Project Overview
This project is a Sales and Customer Analytics Dashboard
developed using Microsoft Power BI.

It provides a visual analysis of sales performance across
departments, products, regions, and sales channels.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis

## 📈 Dashboard Features
- Total Sales Analysis
- Total Quantity Analysis
- Customer Count
- Sales by Department
- Sales by Channel
- Sales by Product
- Sales by Region
- Interactive Department and Region Filters

## 🎯 Project Objective
The objective of this project is to analyze sales data
and present meaningful insights using interactive
visualizations.
